A loader change keeps the game version and changes the loader. Fabric ↔ Quilt and Forge ↔ NeoForge are the close pairs; Fabric ↔ NeoForge needs metadata, entrypoint, event, registry and mixin translation.

What counts as green

1. Builds. The project compiles and the mixin audit passes. 2. Loads. A real client or server starts with the jar and lists the mod. 3. Behaviour. Something observable is asserted in the game — a screen changed, a command ran, a save reloaded. Stop. The port refuses to guess and lists the errors that remain. A hop is never called done at step 1.
