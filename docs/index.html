Modding Accelerator · beta 0.1.0-beta.3

Test a Minecraft mod in seconds. Port it to any version.

One command for mod, plugin and modpack work. It runs your checks in the real game without you opening it, moves your source between Minecraft versions, and finds what breaks a modpack.

Download the betaQuick start

Needs Java 17 or newer. Windows, Linux and macOS. Fabric, NeoForge, Forge and Paper.

# logic tests in seconds, then the real game with no window$ modaccel fast --root my-mod$ modaccel ui-check --root my-mod# move to another Minecraft version; every edit can be undone$ modaccel port --root my-mod --from 1.21.5 --to 1.21.6 --fix# find and repair what breaks a modpack$ modaccel pack-check --pack my-pack.zip --fix
