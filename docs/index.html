What counts as working

Stops with named errorsThe port refuses to guess and lists what is left.
Builds, mixins checkedThe project compiles and the mixin audit passes. Not called working.
Loads in the real gameA real client or server starts with the jar and lists the mod.
Behaviour checked in the gameSomething you can see is asserted: a screen changed, a command ran, a save reloaded.
