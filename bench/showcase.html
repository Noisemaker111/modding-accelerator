Move a Minecraft mod to a new version, and see what actually works.

Goal: any Minecraft version to any other, and any loader to any other.
One command takes a Gradle source project, rewrites it for another Minecraft version, builds it, audits its mixins and then drives the real game for screenshots and assertions. Every run ends with a checked result or a named list of what is left. Beta, published 24 October 2026.

What this does not claim

Loader changes are not supported. Fabric stays Fabric; a port changes the Minecraft version inside one loader.

Source checkouts only. A compiled mod JAR cannot be ported by this tool.

No pixel goldens. Frames are captured for a person or an agent to inspect; nothing compares them to last week's.

Big jumps stop honestly. The 1.21.6 storage and GUI families still need a human; the tool names them.

First use costs more. The first NeoForge port in a repo pays about 40 s of per-project Minecraft setup.

Measured on one machine. Ryzen 9 3900X, Windows 11; the numbers are this repo's own, not a third-party head-to-head.
